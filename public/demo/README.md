# Console walkthrough assets

Place these files here for the Console “Watch how it works” player:

- `console-walkthrough.mp4` — short narrated walkthrough of Max/tx, Daily limit, Approval above, Allow-list, Save policy, and Run the agent.
- `console-poster.jpg` — still frame shown before play (optional; player works without it).

The page embeds `/demo/console-walkthrough.mp4` with `preload="metadata"`. Until the mp4 lands, the UI shows a short “Demo video uploading…” note.
